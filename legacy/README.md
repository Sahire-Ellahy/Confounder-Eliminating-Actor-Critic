# Historical material

`upstream/run_shifting_deepsea_diagnostics.py` is the unmodified standalone
script inherited from the repository's original `main` commit. It is retained
for provenance; use the maintained `ceac` package for current experiments.

The original 2022 `inforatio` tree remains in a local `legacy/inforatio/`
archive. The maintained CEAC installation does not depend on that archive.
The new tabular IDAC port is checked against a small pinned upstream fixture
in `tests/fixtures/idac_upstream.json`; provenance and adapter details are in
[the comparator ledger](../docs/comparator_provenance.md).
